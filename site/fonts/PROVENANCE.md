loading the page makes no request to any other host. Each file is the
latin subset of the family as the Google Fonts CSS API served it on
2026-09-27 (`https://fonts.googleapis.com/css2`, WOFF2), byte-identical
to the download. All three families are under the SIL Open Font License
1.1, whose text is `OFL-1.1.txt` beside them, as the licence requires of
any redistribution; the copyright lines below are the families' licence
